## Veröffentlichung via GitHub Pages

1. Repository auf GitHub erstellen (öffentlich)
2. Alle drei Dateien hochladen
3. **Settings → Pages → Branch: `main` → Ordner: `/ (root)` → Save**
4. Seite ist erreichbar unter: `https://DEIN-USERNAME.github.io/REPO-NAME`
